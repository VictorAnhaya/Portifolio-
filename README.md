# Portfólio — Victor Anhaya

Site pessoal com os sistemas que desenvolvo, um vídeo de apresentação de cada um e contato direto pelo WhatsApp.

- `index.html`: a página inteira (HTML, CSS e JS em um arquivo só)
- `media/`: vídeos de apresentação (`.mp4`) e capas (`.jpg`)

Publicado pelo GitHub Pages a partir da branch `main`.

Para trocar o número de WhatsApp ou os textos de contato, edite o objeto `CONTATO` no começo do `<script>` em `index.html`.
